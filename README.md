# رياضتي 🏃‍♀️💪 — تطبيق الرياضة واللياقة

موقع عربي متكامل للرياضة والحمية، بصفحة واحدة يعمل على الجوال والكمبيوتر، ويحفظ كل بياناتك في متصفحك.

## المميزات
- **اختيار الجنس**: خلفية وردية وكلام بصيغة مؤنثة للبنات، أو خلفية زرقاء وكلام مذكر للأولاد.
- **تمارين اختيارية**: بأثقال أو بدون، في النادى أو في البيت — مع شرح وعدد المجموعات والتكرارات.
- **جدول أسبوعي**: صدر، ظهر، أرجل، أكتاف، ذراعات، بطن، كارديو — بأربعة أنظمة تختار منها.
- **مهام يومية**: تمرين اليوم + المشي 30 دقيقة + شرب 8 أكواب ماء + قياس الوزن، مع شكر وتشجيع واحتفال عند إنجازها.
- **حساب السعرات**: BMR وTDEE وهدف (تخسيس/ثبات/زيادة) + توزيع البروتين والكارب والدهون + مؤشر كتلة الجسم + سجل أكل يومي.
- **وجبات صحية بوصفات**: فطور، غداء، عشاء، ووجبات خفيفة مع المكونات وطريقة التحضير.
- **وجبة الأسبوع المفتوحة**: بعد الانضباط 80%+ خلال الأسبوع تنفتح وجبة مكافأة لذيذة 🍽️
- **تذكيرات**: للتمرين والمشي اليومي وقياس الوزن الأسبوعي (تنبيهات + عدّاد للوقت المتبقي).
- **إنجازي**: إحصائيات الشهر، سلسلة الالتزام، ومكافأة شهرية عند 85% إنجاز 🎁
